Система управления питанием в студенческой столовой
Краткое описание проекта
Веб-приложение для автоматизации процесса заказа питания в студенческой столовой с тремя типами пользователей:

Студенты - просмотр меню, заказ блюд, оставление отзывов, настройка пищевых предпочтений
Повара - управление меню, редактирование блюд, создание заявок на закупку продуктов
Администраторы - общая статистика, обработка заявок на закупку, управление системой
Функциональные возможности
Для студентов:
Просмотр меню с фильтрацией по аллергенам
Оформление заказов
Настройка пищевых предпочтений и аллергий
Просмотр и оставление отзывов о блюдах
История заказов
Для поваров:
Управление меню (добавление/редактирование блюд)
Контроль доступности блюд
Создание заявок на закупку продуктов
Просмотр статистики по заказам
Для администраторов:
Общая статистика системы
Обработка заявок на закупку от поваров
Управление базой данных
Мониторинг активности пользователей
Инструкция по установке/развертыванию
Требования:
Python 3.8 или выше
pip (менеджер пакетов Python)
Установка:
git clone https://github.com/ваш-логин/student-meal-system.git
cd student-meal-system
Создание виртуального окружения:

bash
python -m venv venv
Активация виртуального окружения:

Windows:

bash
venv\Scripts\activate
Linux/Mac:

bash
source venv/bin/activate
Установка зависимостей:

bash
pip install -r requirements.txt
Файл requirements.txt должен содержать:

text
Flask==2.3.3
Flask-SQLAlchemy==3.0.5
Запуск приложения:

bash
python app.py
Доступ к приложению:
Откройте браузер и перейдите по адресу:

text
http://localhost:5000
